# AlienLab – לומדים אנגלית עם החייזר קוסמו

משחק דפדפן חינוכי ללימוד אנגלית לילדים דוברי עברית בגילי 6–12, עם שלוש רמות שמותאמות לתכנית הלימודים של משרד החינוך. הילד לומד מילים יחד עם החייזר קוסמו, ואחר כך מלמד אותו בעצמו, בודק אם הוא הבין ומתקן את הטעויות שלו. יש שלוש רמות קושי לפי טווח גילים.

- **משחק אונליין (GitHub Pages):** https://yotamkarszenbaum.github.io/alienlab/

- **גרסה מפורסמת (Claude):** https://claude.ai/artifact/YSQijrdq58R2vSghzJ5RDh
- **הקובץ המוכן למשחק:** `docs/index.html` — קובץ אחד שעובד בכל דפדפן, גם בלי שרת (אפשר פשוט לפתוח אותו בלחיצה כפולה).

## 1. העלאה ל-GitHub כדי שאפשר יהיה לשחק דרך קישור (GitHub Pages)

אין צורך להתקין כלום. כל השלבים נעשים באתר GitHub.

1. **יוצרים מאגר (repository):** נכנסים ל-github.com ← לוחצים על **+** למעלה ← **New repository**. שם: `alienlab`. בוחרים **Public** (באתר בחינם, GitHub Pages עובד רק עם מאגר ציבורי). לוחצים **Create repository**.
2. **מעלים את הקבצים:** בעמוד המאגר החדש לוחצים על הקישור **uploading an existing file**. פותחים את קובץ ה-ZIP במחשב, נכנסים לתיקייה `alienlab`, מסמנים את **כל מה שבתוכה** (לא את התיקייה עצמה) וגוררים לחלון של GitHub. ממתינים שכל הקבצים יעלו ולוחצים **Commit changes**.
   - חשוב שהתיקייה `docs` תופיע בשורש המאגר (ולא בתוך תיקייה נוספת בשם `alienlab`).
   - אם GitHub מתלונן שיש יותר מ-100 קבצים, מעלים קודם את כל מה שאינו התיקייה `e2e`, ואחר כך את `e2e` בהעלאה שנייה.
3. **מפעילים את האתר:** במאגר ← **Settings** ← בתפריט הצד **Pages**. תחת **Build and deployment** ← **Source** בוחרים **Deploy from a branch**. תחת **Branch** בוחרים `main`, ובתיבה שלידה `/docs` ← **Save**.
4. **מחכים דקה-שתיים** ומרעננים את עמוד ה-Pages. יופיע הקישור למשחק, בצורה:
   `https://<שם-המשתמש-שלכם>.github.io/alienlab/`
   את הקישור הזה אפשר לשלוח לכל אחד, והמשחק ייפתח גם בטלפון.

**עדכון המשחק בעתיד:** אחרי שינוי בקוד מריצים `npm run build:single` (ראו סעיף 2), ומעלים מחדש רק את הקובץ `docs/index.html` (במאגר: נכנסים לתיקייה `docs` ← **Add file** ← **Upload files**). האתר מתעדכן לבד תוך דקה-שתיים.

**למי שמכיר git** — במקום שלב 2:
```bash
cd alienlab
git init && git add . && git commit -m "AlienLab"
git branch -M main
git remote add origin https://github.com/<שם-המשתמש>/alienlab.git
git push -u origin main
```

> הערה: ההתקדמות של כל ילד נשמרת בדפדפן שלו בלבד (localStorage). שום מידע לא נשלח ל-GitHub או לשרת אחר.

**לא רואים את העדכון?** בתחתית מסך הפתיחה מופיע מספר הגרסה (למשל `AlienLab v1.2.0`). אם הוא ישן, עושים רענון מלא: Ctrl+Shift+R, או Cmd+Shift+R במק. אם הגרסה חדשה אבל מופיעה ההתקדמות הקודמת, לוחצים **"משחק חדש מההתחלה"** במסך הפתיחה.

## 2. הפעלה מקומית (למפתחים)

דרישות: Node.js 20.19 ומעלה (נבדק עם Node 22).

```bash
npm install          # התקנת ספריות
npm run dev          # שרת פיתוח: http://localhost:5173
npm test             # 20 בדיקות יחידה למנועים (Vitest)
npm run build        # בנייה רגילה לתיקייה dist/
npm run build:single # בניית קובץ HTML יחיד ל-docs/index.html (זה מה ש-GitHub Pages מציג)
```

בדיקות הקבלה בדפדפן אמיתי (Chrome + playwright-core):
```bash
npm run build:single
npm run e2e:serve &                          # מגיש את docs/ בכתובת localhost:4173
CHROME=/path/to/chrome npm run e2e           # מריץ את 20 בדיקות הקבלה, שומר צילומי מסך ב-e2e/screenshots
```

טכנולוגיות: React 18, TypeScript, Vite, Tailwind CSS 4. ללא שרת, ללא מפתח API וללא שירות AI חיצוני. כל האיורים, דמות החייזר והצלילים נוצרו בקוד (SVG ו-Web Audio), כך שאין קובצי תמונה או שמע בזכויות יוצרים. הגופנים Rubik ו-Fredoka (רישיון OFL) מוטמעים בקובץ.

## 3. מבנה המערכת

```
src/
  content/            נתוני תוכן קבועים — אפשר לשנות מילים ומשימות רק כאן
    words.ts          18 המילים (12 בסיס + 6 לרמות הגבוהות): תרגום, הגייה, מאפיין, דוגמאות, רמה מינימלית
    levels.ts         3 רמות הקושי וטווחי הגילים
    units.ts          3 יחידות, רצף השלבים בכל יחידה, משפטים ומשימות יישום
    items.ts          קטלוג החפצים (סוג, צבע, גודל, מצב) ותיאורם בעברית
  engine/             לוגיקה טהורה, ללא ממשק (נבדקת בבדיקות יחידה)
    alienMind.ts      מנוע הידע של החייזר
    hints.ts          סולם התמיכה והתאמת הקושי
    tasks.ts          מנוע המשימות: בניית שאלה, אפשרויות, הערכת תשובה לפי מילה
    learning.ts       התקדמות לימודית: רמות ידע, תזמון חזרות
    session.ts        רישום ניסיונות, חזרות מאוחרות, יכולות החייזר
    gameProgress.ts   התקדמות משחקית: יחידות, שלבים, פתיחת תחנות, מלאי
    storage.ts        שמירה ב-localStorage, גרסאות, תיקון נתונים פגומים
    clock.ts          שעון מרכזי (כולל כלי בדיקה מסומן להזזת זמן)
  audio/              speech.ts (הגייה עם Web Speech API וזיהוי זמינות), sfx.ts (צלילים ומוזיקה)
  components/         רכיבי ממשק: Alien.tsx (7 מצבי רגש), ItemArt.tsx (איורים), ui.tsx
  screens/            מסכים: פתיחה, היכרות, מעבדה, יחידה, חזרה, "מה קוסמו יודע", אזור הורים
    steps/            שלבי היחידה: גילוי, תרגול, משפט, הרכבת מילים (SpellStep), לימוד-בדיקה-תיקון, משימה, סיכום
  state/              GameContext (מצב ושמירה), nav (ניווט)
tests/                בדיקות יחידה (Vitest)
e2e/                  בדיקות קבלה בדפדפן + תוצאות (results.json) + צילומי מסך
docs/index.html       המשחק הבנוי כקובץ אחד (GitHub Pages)
```

**מסכים:** פתיחה (המשך משחק / משחק חדש מההתחלה / אזור להורים) ← בחירת רמה ← היכרות עם קוסמו ← מעבדה (3 תחנות, תחנת זיכרון כשיש חזרות, "מה קוסמו יודע?") ← יחידה (גילוי ← תרגול ← לימוד החייזר ← בדיקה ← תיקון ← משימה ← סיכום). אזור ההורים נגיש ממסך הפתיחה, מאחורי תרגיל כפל.

**ניווט ומצבי קצה:** כפתור "אחורה" של הדפדפן מחזיר תמיד למסך בטוח (מעבדה/פתיחה). ההתקדמות נשמרת אחרי כל פעולה. רענון באמצע שלב מחזיר לתחילת אותו שלב, ובשלב "בדיקת החייזר" למצב השמור (החייזר בוחר שוב את אותו הדבר). לחיצות מהירות כפולות נחסמות. כפתור "המשך" נעול עד שבוחרים תשובה, ומציג הודעה ידידותית. ילד שלא עונה 16 שניות מקבל עידוד, בלי עונש. יחידה נעולה מציגה הסבר. שגיאה בלתי צפויה מציגה הודעה בעברית עם "לנסות שוב".

### רמות קושי לפי גיל

| רמה | גילים | מה כוללת |
|---|---|---|
| ⭐ צוערי חלל | 6–7 (לפני לימודי אנגלית בבית הספר) | 12 מילים. הכול בהקשבה ובתמונות, בלי צורך לקרוא. בכל תחנה **"קוסמו אומר"**: קוסמו קורא למילה, והילד מוצא אותה בתוך סצנה של המעבדה |
| ⭐⭐ חוקרי חלל | 8–9 (כיתות ג–ד, Pre-A1) | 18 מילים. המילים הבסיסיות לא מוסברות מחדש: כל תחנה נפתחת ב**"קוסמו מתבלבל"** (צירופים קצרים כמו I SEE A RED BALL), והסבב חוזר באמצע התחנה עם המילים החדשות. **איות מילים קצרות** (CAT, DOG, RED, BIG, BOX, KEY), **השלמת משפטים ממאגר מילים** ("I SEE A ___."), **בניית משפטים** מקוביות מילים, וקוסמו לומד גם GREEN ו-CLOSE |
| ⭐⭐⭐ מפקדי חלל | 10–12 (כיתות ה–ו, A1) | 25 מילים. **"קוסמו מתבלבל" במשפטים מלאים** (THE BALL IS ON THE TABLE, THERE ARE TWO BIG DOGS), כולל טעויות דקדוק (THERE IS ← THERE ARE). **מספרים ורבים** (THREE RED BALLS), **THERE IS / THERE ARE**, **מילות מיקום IN / ON / UNDER**, **קריאת הודעה קצרה** ושאלות הבנה, משפטים ארוכים (THE CAT IS ON THE TABLE), איות מילים ארוכות יותר, קוסמו לומד UNDER, ו**דוגמאות נגדיות** בלימוד |

### התאמה לתכנית הלימודים של משרד החינוך

הרמות מבוססות על תכנית הלימודים באנגלית של משרד החינוך (English Curriculum 2020 for Elementary School) ועל הנחיות שלב ה-Pre-Foundation:

- אנגלית היא מקצוע חובה מכיתה ג'. לכן רמה 1 (גילי 6–7) בנויה כחשיפה ראשונה, בהקשבה ובתמונות.
- **כיתה ג' (Pre-A1):** בסוף השלב הילדים מכירים כ-200 מילים, מפענחים ומאייתים מילים קצרות של עיצור-תנועה-עיצור (CVC), ומשלימים משפטים קצרים ממאגר מילים. מכאן ברמה 2: איות מילים קצרות והשלמת משפטים.
- **כיתות ד–ו (A1):** בסוף כיתה ו' מצופה היכרות עם כ-1,200 מילים. הדקדוק כולל THERE IS / THERE ARE, שמות תואר לפני שם עצם, רבים, מילות יחס של מקום (IN / ON / UNDER), ציווי ו-to be, והקריאה כוללת הודעות וסיפורים קצרים עם איורים. מכאן ברמה 3: מספרים ורבים, THERE IS / ARE, מילות מיקום, משפטים מלאים וקריאת הודעה.
- המשחק **דוגם** את התכנית ולא מכסה אותה: יש בו 25 מילים ולא מאות. המטרה היא שסוג המשימות והדקדוק יתאימו לגיל. מומלץ שמורה לאנגלית בבית ספר יסודי יעבור על רשימות המילים, כי בתי ספר שונים משתמשים בספרי לימוד שונים.

מקורות: [English Curriculum 2020 – Elementary](https://meyda.education.gov.il/files/Mazkirut_Pedagogit/English/curriculum2020Elementary.pdf), [Pre-Foundation Can-Do Descriptors](https://meyda.education.gov.il/files/Mazkirut_Pedagogit/English/prefoundationcando.pdf).

### פרטי הפעילויות

- הרמה נבחרת בתחילת משחק חדש, לפי טווח גילים. בהתאם למפרט, המשחק לא שואל גיל מדויק.
- את הרמה אפשר לשנות בכל רגע באזור ההורים. כשמעלים רמה, תחנה שכבר הושלמה מסומנת "✨ יש כאן פעילויות חדשות!", והשלבים החדשים מופיעים בה. כשמורידים רמה, השלבים הנוספים מוסתרים, אבל הנתונים שלהם לא נמחקים.
- **"קוסמו מתבלבל" (רמות 2–3):** ברמות הגבוהות המילים הבסיסיות לא מוסברות מחדש. במקום זה כל תחנה נפתחת בקוסמו: הוא מסתכל על תמונה ואומר באנגלית מה הוא רואה, אבל לפעמים מתבלבל ("I SEE A BIG BALL" כשבתמונה כלב גדול). הילד מחליט אם קוסמו צודק. אם לא, הוא לוחץ על המילה השגויה ובוחר במה להחליף אותה. בחלק מהסבבים קוסמו דווקא צודק, כדי שהילד יבדוק כל מילה ולא ינחש שתמיד יש טעות. ברמה 2 המשפטים קצרים (I SEE A RED BALL), וברמה 3 הם מלאים: IS/ARE, מספרים ורבים ו-IN/ON/UNDER (THE BALL IS ON THE TABLE כשהכדור מתחת לשולחן, THERE IS THREE CATS). אחרי טעות יש רמזים מדורגים: קודם על מה להסתכל, אחר כך המילה השגויה זוהרת, ובסוף התשובה. בסוף כל סבב מוצגים המשפט הנכון, התרגום ותזכורת קצרה למילים שהיו קשות.
  - **בפתיחת התחנה:** מילה שהילד טיפל בה לבד בכל הסבבים מדלגת על ההיכרות ועל התרגול שלה. מילה שנדרשה בה עזרה מדלגת רק על מסך ההיכרות, כי הסבב כבר הציג אותה, ומקבלת שאלת תרגול אחת. המילים החדשות של הרמה תמיד נלמדות. כשמעלים רמה אחרי שכל המילים הבסיסיות כבר נלמדו, הפתיחה מדלגת על עצמה.
  - **באמצע התחנה:** סבב נוסף של "קוסמו מתבלבל" עם המילים החדשות מחליף את סבב התרגול המעורב של רמה 1. בתחנה 3 הוא מחליף את שאלות המשפט OPEN THE DOOR.
- **קוסמו משתתף לאורך כל התחנה (רמות 2–3):** מילה חדשה מוצגת גם בתוך משפט קצר שבנוי ממילים שהילד כבר מכיר ("I HAVE A RED CAR." — יש לי מכונית אדומה), עם תמונה והשמעה. באיות קוסמו כותב קודם את המילה "כמו שהיא נשמעת לו", כלומר בטעות נפוצה של דוברי עברית (KAT, BEEG, TRI, GRIN, SMOL, TEIBEL), והילד מתקן אותו. בהשלמת משפטים קוסמו "שכח מילה", ובבניית משפטים "המילים שלו התערבבו".
- **"קוסמו אומר" (רמה 1):** ארבעה סבבים בכל תחנה. הסצנה קבועה, עם 5 חפצים על מדף ועל הרצפה, ובכל סבב יש בדיוק חפץ אחד שמתאים למילה. פריט גדול מקבל מקום גדול יותר בחדר.
- **איות (רמות 2–3):** הילד רואה תמונה ומילה בעברית, יכול לשמוע את המילה, ומרכיב אותה באנגלית בלחיצה על אותיות (שתיים מהן מיותרות). ברמה 2 מאייתים מילים בנות 3 אותיות, וברמה 3 מילים ארוכות יותר (APPLE, GREEN, SMALL, THREE, TABLE, OPEN). אחרי ניסיון שגוי, האותיות שבמקום הנכון נשארות ירוקות. הרמזים לא כותבים את המילה לפני הרמה השלישית. האיות נשמר **בנפרד** מהזיהוי.
- **השלמת משפטים (רמות 2–3):** תמונה ומשפט עם מקום ריק ("THE BALL IS ___."), התרגום לעברית, ו-2–3 מילים לבחירה. ברמה 3 נוסף דקדוק: THERE IS / THERE ARE ו-IN / ON / UNDER. רמז ראשון: הסבר קצר, למשל "כשיש הרבה אומרים THERE ARE". בהמשך האפשרויות מצטמצמות, ולבסוף התשובה זוהרת.
- **בניית משפטים (רמות 2–3):** תמונה ומשפט בעברית, והילד לוחץ על קוביות המילים באנגלית לפי הסדר. יש גם קובייה מיותרת. ברמה 3 המשפטים ארוכים יותר, כוללים רבים ו-THERE ARE, למשל THERE ARE TWO BALLS IN THE BOX. שגיאת סדר מעלה את רמת העזרה, אבל לא נרשמת כטעות במילה.
- **קריאת הודעה (רמה 3):** הודעה של 4 משפטים מ"מפקד החללית" ושלוש שאלות הבנה בעברית ("איפה הכדור האדום?"). עונים בבחירת תמונה. הרמז הראשון מדגיש את המשפט שבו נמצאת התשובה, ואפשר גם לשמוע אותו.
- **דוגמאות נגדיות (רמה 3):** במסך הלימוד ובמסך התיקון יש מתג "✓ זה RED / ✗ זה לא RED". כל מאפיין שיש לדוגמה נגדית לא יכול להיות משמעות המילה.
- **קוסמו לומד UNDER (רמה 3):** אותו מנגנון לימוד. אחרי "כדור אדום מתחת לשולחן" קוסמו חושב ש-UNDER זה כדור, ובבדיקה הוא בוחר כדור **על** השולחן. דוגמה של חתול מתחת לשולחן מתקנת אותו.

רצף בכל יחידה: ברמות 2–3 פתיחה של **"קוסמו מתבלבל"**; לכל מילה **גילוי** ואז **תרגול** (ברמות 2–3 רק למילים שצריך); סבב תרגול מעורב (ברמות 2–3: סבב נוסף של "קוסמו מתבלבל"); פעילויות לפי הרמה; **לימוד החייזר ← בדיקה ← תיקון**; **משימת יישום** שמשלבת מילים מיחידות קודמות; **סיכום**. היחידה הבאה נפתחת כשמסיימים את פעילויות הליבה, גם אם נעזרו ברמזים.

**סוגי המשימות:**
1. זיהוי מילה לפי תמונה (תמונה ← בחירת המילה האנגלית, עם כפתור שמע לכל מילה).
2. בחירת תמונה לפי מילה מוצגת או מושמעת (אחרי 2 הצלחות עצמאיות: רק שמע, אם יש קול במכשיר).
3. בחירת דוגמה כדי ללמד את החייזר.
4. בדיקת החלטה של החייזר ("קוסמו צדק?").
5. בחירת דוגמה מתקנת.
6. משימה המשלבת מילים (כולל משפטים ופעולות שמשנות את הסצנה: מפתח נאסף, דלת נפתחת).
7. איות: הרכבת מילה מאותיות (רמות 2–3).
8. בניית משפט מקוביות מילים (רמות 2–3).
9. "קוסמו אומר": מציאת המילה בתוך סצנה (רמה 1).
10. השלמת משפט ממאגר מילים (רמות 2–3).
11. קריאת הודעה קצרה ומענה על שאלות הבנה (רמה 3).
12. "קוסמו מתבלבל": שיפוט משפט של קוסמו, מציאת המילה השגויה ותיקונה (רמות 2–3).

**הוספת מילה:** מוסיפים רשומה ל-`WORDS` ב-`src/content/words.ts` (מאפיין, דוגמאות חיוביות ושליליות, משפט גילוי, ואם צריך `minLevel`), ומוסיפים את המזהה לשלבי יחידה ב-`units.ts`. בדיקת יחידה מוודאת שבשום רמה לא משתמשים במילה לפני שהוצגה. אין צורך לגעת ברכיבי הממשק. כדי שהחייזר יוכל ללמוד אותה, מוסיפים לה שדה `teach`.

## 5. מנגנון הידע של החייזר (`src/engine/alienMind.ts`)

המנגנון מבוסס כללים ודטרמיניסטי, ואין בו בחירה אקראית ואף לא מודל AI.

1. **מאפיינים:** כל תמונה מתוארת במאפיינים: סוג (תפוח, כדור…), צבע, ורק כשהם בולטים גם גודל (גדול/קטן), מצב (פתוח/סגור), כמות (2 או 3) ומיקום (IN / ON / UNDER). השולחן או הקופסה שהחפץ נמצא עליהם הם רקע, ולא מאפיין של החפץ.
2. **ההשערה של החייזר:** המאפיינים המשותפים לכל הדוגמאות שהילד הראה (חיתוך).
3. **הטיה קבועה:** אם נשארו כמה מאפיינים אפשריים, החייזר מנחש לפי הסדר **סוג ← צבע ← גודל ← מצב ← כמות ← מיקום** ("הטיית צורה", כמו אצל ילדים צעירים).
4. **מצבי הבנה:** לא שמע / שמע את המילה / **אי-הבנה** (הניחוש שגוי) / **הבנה חלקית** (הניחוש נכון, אבל עדיין אפשריים מאפיינים נוספים) / **מבין**.
5. **בדיקה:** סצנת הבדיקה נבנית כך שבדיוק פריט אחד מתאים לניחוש של החייזר. החייזר בוחר אותו, ולכן הטעות שלו נובעת ישירות מהדוגמאות שקיבל.
6. **תיקון:** דוגמה עוזרת רק אם היא מוציאה את המאפיין השגוי מהחיתוך. תפוח אדום נוסף לא משנה דבר, כדור כחול נדחה (לא אדום ולכן לא נלמד), וכדור אדום מוציא את "תפוח" ומשאיר את "אדום".
7. **אישור הילד מלמד:** כשהחייזר צודק בבדיקה והילד מאשר, הפריט נוסף כדוגמה. כך הבנה חלקית הופכת להבנה מלאה.
8. **יכולות:** רק כשהמושג במצב "מבין", החייזר מקבל יכולת (מוצא כלבים / ממיין לפי צבע / משווה גדלים / פותח דלתות, ומרמה 2 גם מוצא דברים ירוקים / סוגר דלתות וקופסאות), ומשימת היחידה דורשת את היכולת הזאת.
9. **דוגמאות נגדיות (רמה 3):** ההשערה היא המאפיינים המשותפים לכל הדוגמאות, **פחות** כל מאפיין שמופיע בדוגמה נגדית. דוגמה נגדית קרובה (תפוח ירוק מול תפוח אדום) היא הדוגמה הכי מועילה, כי היא מוציאה בדיוק את המאפיין השגוי.

**הדוגמה של RED, כפי שהיא רצה במשחק:** תפוח אדום ← "RED = תפוח" (אי-הבנה) ← בבדיקה החייזר בוחר **תפוח ירוק** ← הילד מסמן "טעה" ← "נראה שקוסמו חושב ש-RED זה תפוח. איך נראה לו ש-RED זה צבע?" ← כדור אדום ← "RED = הצבע האדום" ← בבדיקה חוזרת החייזר בוחר כוס אדומה ← "אהה! עכשיו אני מבין! RED זה הצבע האדום, לא תפוח!".

ב-BIG אפשר לראות שתי טעויות ברצף: כדור כחול גדול נותן "BIG = כדור". כוס כחולה גדולה נותנת "BIG = כחול". כוכב צהוב גדול מוביל להבנה מלאה.

את המודל אפשר לראות במסך **"מה קוסמו יודע?"** (לילד) ובטבלה באזור ההורים.

## 6. רמזים והתאמת קושי (`src/engine/hints.ts`)

| רמה | מתי | מה מוצג |
|---|---|---|
| 1 – הסבר | טעות ראשונה או לחיצה ראשונה על "עזרה" | "לא נורא, בואו ננסה יחד", המילה מושמעת שוב, תרגום והגייה בעברית |
| 2 – צמצום/הדגשה | טעות שנייה או לחיצה שנייה | נשארות 2 אפשרויות, וטיפ על המאפיין ("שימו לב לצבע"). בלימוד החייזר: הדוגמאות המתאימות זוהרות |
| 3 – הדגמה | המשך התקשות | התשובה זוהרת, ואחרי שהילד בוחר בה מוצגת **משימה קלה ושונה** עם אותה מילה (תמונה אחרת, שתי אפשרויות) |

- כפתור "עזרה" קיים בכל מסך משימה. הוא מעלה רמה אחת בכל לחיצה, ולכן מציג רמז ולא את הפתרון. אפשר לחזור לרמה קלה יותר ("פחות עזרה").
- **הצלחה עצמאית** = נכון בניסיון הראשון, בלי עזרה ובלי טעות קודמת. **הצלחה בעזרת רמז** נשמרת בנפרד, והמילה מסומנת לתרגול עצמאי.
- **התאמת קושי:** מספר האפשרויות עולה עם ההצלחות העצמאיות (2 ← 3 ← 4). אחרי 2 הצלחות עצמאיות המילה מוצגת רק כשמע (אם יש קול במכשיר). בחזרות משתמשים בתמונות אחרות מאלה של הלמידה.
- **משימות עם כמה מילים** מנותחות לפי מילה: תפוח ירוק במקום RED APPLE נרשם כטעות ב-RED בלבד.
- אין פסילה, אין "חיים" ואין מגבלת זמן. ההתאמה מבוססת על ביצועים בלבד, בלי שום אבחון.

**חזרות (`learning.ts`):** מילה שהילד התקשה בה חוזרת אחרי 4 שעות, מילה שזוהתה רק בעזרה אחרי 8 שעות, מילה שזוהתה לבד אחרי 24 שעות, ואחרי חזרה מוצלחת אחרי 3 ימים. חזרה נחשבת "מאוחרת" רק כשהמילה הגיעה למועד החזרה שלה ועברו לפחות 4 שעות מהתרגול האחרון. החזרה משולבת בסיפור ("מכונת הזיכרון של קוסמו"). באזור ההורים יש **כלי בדיקה מסומן** שמזיז את שעון המשחק ביום, כדי שאפשר יהיה לבדוק את המנגנון בלי לחכות.

8. אחרי דוגמה נגדית, קוסמו אמר "מה דומה בין כל אלה?" גם כשהייתה רק דוגמה אחת. הנוסח הוחלף ב"אז RED זה לא תפוח — RED זה הצבע האדום!".
9. ההבדל בין "גדול" ל"קטן" לא היה ברור מספיק (מדווח על ידי המשתמש). ניגודיות הגודל הוגדלה: פריט קטן מצויר עכשיו ב-42% מגודל הכרטיס במקום 56%, ופריט גדול גבוה ממנו בערך פי 2.5. ב"קוסמו אומר" פריט גדול מקבל גם מקום גדול יותר בחדר.
10. בבדיקת התוכן התגלה שמשימת רמה 3 בתחנה 2 ("THREE YELLOW STARS") השתמשה במילה STAR לפני שנלמדה (STAR נלמדת בתחנה 3). המשימה הוחלפה ב-THREE YELLOW BALLS.
11. הכרטיסים של בחירת הרמה ושל התחנות "קפצו" כשהעכבר עמד על הקצה שלהם (אפקט ריחוף שהזיז אותם). האפקט הוחלף בהדגשה שלא מזיזה את הכרטיס.
12. בציור "בתוך הקופסה" החפץ כמעט לא נראה. הציור תוקן כך שהחפץ בולט מהקופסה.
13. בבדיקה החזותית של "קוסמו מתבלבל" התגלה שמשפט אנגלי שלם עם נקודה, בתוך בועת הדיבור העברית, מוצג בסדר הפוך ועם נקודה כפולה. הבועה מציגה עכשיו רק את המילה שתוקנה, והמשפט המלא והתרגום מוצגים בכרטיס.
14. במסך הטלפון התמונה של "קוסמו מתבלבל" הייתה קטנה מדי (בעיקר פריט "קטן"). התמונה הוגדלה.

## 9. מגבלות ותכונות שעדיין לא פועלות

- **שמע:** ההגייה משתמשת בקולות שמותקנים במכשיר (Web Speech API). בטלפונים ובמחשבים רגילים יש בדרך כלל קול אנגלי, וקול עברי לא תמיד קיים. כשאין קול, הכפתור מציג "אין קול במכשיר הזה" ואת ההגייה באותיות עבריות (APPLE = אֶפֶּל). ההשמעה נבדקה עם מנוע דיבור מדומה ועם דפדפן בלי קולות, אבל **לא נבדקה על מכשירים פיזיים**. אין בגרסה קובצי שמע מוקלטים.
- **הקראת ההוראות בעברית** פועלת רק כשיש במכשיר קול עברי (אפשר לכבות באזור ההורים).
- המשחק בודק **זיהוי משמעות ובחירה מתוך אפשרויות**, וברמה 3 גם **הרכבת מילה מאותיות נתונות**. הוא לא בודק כתיבה חופשית או הגייה, ואין בו זיהוי דיבור.
- כשמעלים רמה אחרי שתחנה כבר הושלמה, המילים החדשות נלמדות בשלבי גילוי ותרגול. סבב התרגול והמשימה של אותה תחנה לא משוחקים שוב.
- "ללמד את החייזר" עובד על 4 מושגים ברמה 1 (DOG, ‏RED, ‏BIG, ‏OPEN), ועל 6 מושגים מרמה 2 (גם GREEN ו-CLOSE). את שאר המילים החייזר "שומע" יחד עם הילד, אבל לא לומד מדוגמאות.
- "קוסמו אומר" נועד לרמה 1 בלבד, ובניית משפטים לרמות 2–3. בתחנה הראשונה אין בניית משפטים, כי עדיין אין בה מילים שאפשר לחבר.
- המשחק **דוגם** את תכנית הלימודים ולא מכסה אותה: 25 מילים מתוך כ-1,200 שמצופות בסוף כיתה ו', ומבנים דקדוקיים נבחרים. מומלץ שמורה יעבור על התוכן.
- פריטי דקדוק בלבד (THERE IS / THERE ARE) לא נרשמים בנתוני ההתקדמות לפי מילה, כי הם לא מילים במאגר. השלמה נכונה שלהם רק מקדמת את המשחק.
- קריאת ההודעה כוללת הודעה אחת (בתחנה 3). אין עדיין סיפורים ארוכים יותר.
- המשפטים מוגבלים ל-OPEN/CLOSE THE DOOR, והמילה THE מוסברת בקצרה ולא נלמדת כמילה.
- רענון באמצע שלב תרגול מחזיר לתחילת אותו שלב (השמירה היא ברמת שלב, והניסיונות שכבר נעשו נשמרים).
- ההתקדמות נשמרת במכשיר אחד, ואין פרופילים: כמה ילדים על אותו מכשיר חולקים את אותה התקדמות.
- מחסום אזור ההורים הוא תרגיל כפל פשוט, לא מערכת אבטחה.
- כלי הזזת השעון באזור ההורים הוא כלי בדיקה למפתחים, והוא מסומן ככזה.
- התוכן מנוסח בלשון רבים ("בואו", "לחצו") כדי לפנות לכל הילדים.
- התאמה חכמה מורכבת, יצירת תוכן ב-AI, חשבונות ענן, מערכת מורים ושפות נוספות לא מומשו (עדיפות שלישית באפיון).
